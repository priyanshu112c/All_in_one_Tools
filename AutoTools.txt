Develop a comprehensive, high-performance, and responsive multi-tool web application that incorporates all the functionalities listed below. The application must be built using a modern frontend framework (such as React, Vue, or Next.js) and must rely exclusively on client-side JavaScript libraries to ensure all tools function directly in the browser without a backend.

### Technical Requirements:
1. **Architecture:** Create a modular architecture where each tool is a separate, reusable component. Use a centralized routing system to navigate between categories and individual tools.
2. **Functionality:** Ensure every tool listed is fully operational. For tools requiring specific logic, implement the following libraries:
    - **PDF Manipulation:** `pdf-lib`
    - **Image Processing:** `browser-image-compression`, `Cropper.js`, and `html2canvas`
    - **QR/Barcode:** `qrcode` and `jsQR`
    - **Cryptography/Security:** `CryptoJS`
    - **Date/Time:** `Day.js`
    - **Mathematics:** `Math.js`
    - **File Handling:** `FileSaver.js`
3. **Design System:**
    - **Theme:** A professional, modern "Blue and White" aesthetic. Use a clean white background with various shades of professional blue (e.g., Navy, Royal Blue, and Sky Blue) for accents, buttons, and headers.
    - **UI/UX:** Implement a sleek, card-based layout for tool selection. Use high-quality typography and plenty of whitespace to prevent clutter.
    - **Animations:** Integrate smooth transitions and micro-interactions using a library like Framer Motion or GSAP. Include hover effects on tool cards, loading skeletons, and smooth page transitions.
    - **Responsiveness:** The layout must be fully mobile-responsive, utilizing a grid system that adjusts from multi-column desktop views to single-column mobile views.
4. **User Interface Features:**
    - A searchable sidebar or top navigation bar categorized by tool type.
    - A "Favorites" or "Recently Used" section.
    - A "Copy to Clipboard" feature for all text-based outputs.
    - Dark/Light mode toggle (defaulting to the Blue/White theme).
